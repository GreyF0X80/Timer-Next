# Timer 2.0.0 — Privacy Policy

Effective date: 30 July 2026

## Overview

Timer is an offline-first interval timer. The current web/PWA release does not require an account and does not include advertising, analytics, cloud synchronization or a backend service.

## Data stored on the device

Timer stores the following information locally in the browser:

- saved workout configurations and names;
- application preferences, language and theme settings;
- custom branding colors and name;
- a personal logo, when supplied by the user, in IndexedDB.

This information is used only to provide the requested functions on the same device and browser profile.

## Data transmission

The current PWA does not transmit workout data, preferences, custom branding or a personal logo to a Timer server. Normal web-hosting infrastructure may process technical connection data such as IP address, date, time and requested files according to the hosting provider's own policies.

## Permissions and device features

Timer may request or use browser capabilities when available:

- audio playback after user interaction;
- vibration;
- Screen Wake Lock;
- local browser storage and offline cache.

These capabilities do not add account, HealthKit, Apple Health, Google Health Connect or cloud functionality.

## Deleting local data

Users can reset application preferences from Timer. Saved workouts can be deleted from the workout library. All remaining local data, including the offline cache and IndexedDB logo, can be removed through the browser's site-data controls or by uninstalling the PWA and clearing the site's stored data.

## Children and sensitive data

Timer is a general fitness timing utility and is not designed to collect personal, health or sensitive data. Users should not place sensitive information in workout names or custom branding fields.

## Changes

If future versions introduce accounts, analytics, synchronization, health-platform access or other online processing, this policy must be revised before those functions are released.

## Support

See `SUPPORT.md` in the distribution package for support and troubleshooting information.
